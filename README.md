# .github

This is the [BLIT386](https://github.com/blit386) GitHub organization's special `.github` repository. It holds the
org-wide profile and the default community-health files that other repos in the organization fall back to when they do
not define their own.

- Org profile: [`profile/README.md`](profile/README.md) – renders on [github.com/blit386](https://github.com/blit386)
- Default code of conduct: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
- [`CODEOWNERS`](CODEOWNERS) – applies to this repository only. A `CODEOWNERS` here is not org-wide.

Both [blit386/blit386](https://github.com/blit386/blit386) and
[awesome-blit386](https://github.com/blit386/awesome-blit386) define their own code of conduct, so today the default
covers only this repository. It stays as a floor for whatever the org adds next.

Looking for the engine itself? Start at [blit386/blit386](https://github.com/blit386/blit386) or the docs at
[blit386.dev](https://blit386.dev). The curated list of games, tools, and resources lives at
[awesome-blit386](https://github.com/blit386/awesome-blit386).
